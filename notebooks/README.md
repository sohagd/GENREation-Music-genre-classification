# Notebook deliverable

Create `music_genre_classification.ipynb` here for exploratory analysis and demonstration. Recommended notebook sections:
1. Project objective and imports
2. Dataset inspection and genre counts
3. Waveform and spectrogram examples
4. MFCC extraction example using `src.audio_features.extract_mfcc`
5. Training command / model summary
6. Evaluation metrics and confusion matrix
7. Example prediction and lessons learned

The reproducible training pipeline is in `train.py`; this avoids duplicating model code in the notebook.
